## Overview
This repository contains an **Exploratory Data Analysis (EDA)** project developed in **Python** using the **Goodbooks-10k dataset**. The project leverages the **pandas** library to process, clean, transform, and extract meaningful insights from a database consisting of books, user ratings, and to-read lists.

This project was developed as part of an **academic practical assignment** to demonstrate proficiency in handling large-scale datasets and performing basic statistical analysis.

---

## Objectives

- Explore and manipulate **large-scale datasets** using `pandas`.
- Perform **data cleaning**, including data type handling and column renaming.
- Transform data to create **custom metrics**, such as a *popularity index*.
- Execute analytical queries to extract insights, such as:
  - Identifying the **most popular books**
  - Analyzing the **distribution of user ratings**
  - Performing **cross-reference analysis** between *to-read lists* and book metadata

---

## Dataset

This project utilizes the following CSV files:

- **books.csv**  
  Contains book metadata such as title, author, publication year, and ratings.

- **ratings.csv**  
  Historical data of ratings provided by users.

- **to_read.csv**  
  User-generated lists of books they intend to read.
